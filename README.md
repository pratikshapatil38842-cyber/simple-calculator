NOVA Smart Calculator 🧮

About the Project

NOVA Smart Calculator is a simple and attractive web application designed to perform basic mathematical calculations. It features a modern dark theme and a responsive user interface.

Features

- Addition, subtraction, multiplication, and division
- Clear (AC) and delete (DEL) buttons
- Positive/negative number toggle
- Decimal number calculations
- Error handling for division by zero
- Responsive design for different screen sizes

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

- "index.html" — Defines the calculator structure.
- "style.css" — Styles the calculator interface.
- "script.js" — Handles calculator operations and functionality.

Live Demo

https://pratikshapatil38842-cyber.github.io/simple-calculator/

How to Use

1. Open the live demo link.
2. Enter numbers using the calculator buttons.
3. Select an arithmetic operator.
4. Enter the next number.
5. Press "=" to view the result.
6. Use "AC" to clear the calculation.
